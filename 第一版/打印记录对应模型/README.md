## 琴键

[十键整套打印排布](10键整套_打印排布.stl) 是 R7g 版本，包含 7 个音级键和 3 个修饰键，共 10 个独立零件。打印历史有使用同名文件拆分出的部分琴键的成功记录，但记录不含源文件哈希，也不能确认当前装在琴上的各个键分别是哪一版。

其余小零件及琴键的实物对应版本仍待核对；不要把这些模型当作完整可直接复刻的整机套件。
