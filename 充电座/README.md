# 12V 锂电池充电母座固定试件

这是用于固定充电母座的 3D 打印局部试配件。蓝色底座容纳母座并限制其移动，方便充电插头插拔。

## 插合实物

![充电母座与充电插头插合实物](../图片/充电插头插合实物.jpg)

照片展示充电母座与充电插头的插合状态。

## 文件与尺寸

- [STL 模型](12v锂电池母座固定3D模型.stl)：用于切片打印。
- [STEP 模型](12v锂电池母座固定3D模型.step)：便于查看和修改。
- [模型生成源码](充电座模型生成源码.step.py)：使用 Python 和 build123d。

母座实测外径约 12 mm，硬直段约 19 mm；试件包络约 32 × 34 × 14 mm。接头形状和打印公差会影响配合，其他型号需试配。

## 试配记录

作者实测：试件无盖插拔 10 次母座未移动，图示插合状态能正常充电。长期耐久、线根受力及整机安装仍待验证；此文件是局部试件，并非整机底壳。
