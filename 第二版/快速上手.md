# 迷你电子琴 2.0 快速上手

本指南对应 `0.6.39-board2_1`。操作已对照固件源码和模拟测试，实机验收待完成。你可以在「设备状态」查看琴上运行的固件版本。

## 怎么进入设置？

**在开机后的演奏画面，单独按住最右边的琴键（HIGH）约 1.2 秒，看到「首页」就松手。** 音色、音量、演奏界面等设置都从这个菜单进入。长按时请先松开其他琴键。

[看菜单首页与音量设置画面](界面展示/README.md) · [用同样的按键在线练习](https://xxy608.github.io/esp32-mini-piano/try/full/)

| 在菜单里 | 按键 |
|---|---|
| 移动到上一项 / 下一项 | 数字键 **1** / **2** |
| 进入选中项或确认编辑 | 数字键 **3** |
| 返回上一级或取消编辑 | 数字键 **4** |
| 直接退出菜单，回到演奏画面 | 短按最右键 **HIGH**。正在编辑的项目会取消。 |

## 第一次试弹或播放

1. 打开菜单，选「选择歌曲」。第一次可以选「内置音阶」，按 **3** 后会直接进入「演奏模式」。
2. 用 **1 / 2** 选「简单 单音」，按 **3** 确认。有多音原谱的曲目也可以选「复杂 多音」。
3. 在下一页选「开始演奏」跟弹，或选「播放音乐」自动播放。如果提示「没有多音原谱，请选单音」，把该页的「播放模式」切回单音；要跟弹时也可以按 **4** 返回模式列表，改选「简单 单音」。
4. 自动播放时，单独短按并松开 **LOW** 可以暂停或继续。LOW 是最右侧三个修饰键中靠左的那个。

## 常用设置在哪里？

从菜单首页用 **1 / 2** 选择，按 **3** 进入。

| 我想做什么 | 菜单路径 |
|---|---|
| 调音量 | 「音色与音量」→「音量」。弹窗里 **1** 加 1%，**2** 减 1%，长按连续调节，**3** 保存，**4** 取消。 |
| 换音色 | 「音色与音量」→「选择音色」。用 **1 / 2** 浏览，按 **3** 应用。 |
| 切换屏幕上的演奏方式 | 「演奏界面」→「简谱演奏」或「音游演奏」。 |
| 调速度、节拍器或移调 | 「演奏界面」→「节奏与调性」。 |
| 打开歌词 | 选曲并确认演奏模式后，在「开始演奏」同一页找到「显示歌词」。曲谱需自带歌词。 |
| 连接手机或导入歌曲 | 「手机连接」。手机连上屏幕显示的 Wi-Fi，再用浏览器打开屏幕显示的地址，在网页上传曲谱。 |
| 查看固件版本、存储状态或检查按键 | 「设备状态」。选「逐键检查」可查看琴是否识别到各键。 |
