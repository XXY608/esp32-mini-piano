# 网页在线曲库

在线曲库由本站提供曲谱目录和琴端 JSON。可按中文名、英文名或作曲者搜索，同一首只加入一次。网页将曲谱交给固件解析，成功后保存在当前浏览器。电脑端虫虫选曲使用独立服务，网页曲库检索本站收录；未收录时可用原关键词在虫虫钢琴另开标签页查询，或导入已有 TXT／琴端 JSON。

这些版本是为迷你电子琴重新编写的传统及古典练习谱。曲库标注的 BPM 为该练习谱的设定。《小星星》《欢乐颂》附有本项目编写的简易伴奏，《铃儿响叮当》收录副歌。其余曲目为单音。历史曲调参考见 [Mozart 变奏主题](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=2236)、[贝多芬的欢乐颂](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=528) 和 [Jingle Bells 历史乐谱](https://www.loc.gov/item/2023838067/)。

新增或修改曲目时，编辑 Build-OnlineCatalog.cjs，运行 node Build-OnlineCatalog.cjs。脚本对每小节验拍，调用固件网页的曲谱校验，生成索引与曲谱文件。
