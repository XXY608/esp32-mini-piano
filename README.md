# ESP32 迷你电子琴

这是基于 ESP32-S3 的迷你电子琴项目。第一版实物使用 7 个音级键和 3 个修饰键，配有 TFT 屏幕、扬声器和 Wi-Fi 网页，支持曲谱播放与练习。

![第一版实物内部](图片/第一版实物内部.jpg)

## 文件与说明

- [12V 锂电池充电母座固定试件](充电座说明.md)：STEP、STL、插合照片和试配记录。
- [第一版打印记录对应模型](第一版/打印记录对应模型/README.md)：已找到四个打印记录对应名称的模型，实物逐件对应仍待确认。
- [第一版 ESP32 固件](第一版/固件/README.md)：实物已烧录的 0.6.16 固件源码、接线、编译环境与验证状态。

第一版其他外壳、琴键与 PCB 的实物对应文件仍在核对；目前不是完整整机复刻包。第二版机械轴外壳仍在研究中。
