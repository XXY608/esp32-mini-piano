# 🎹 你好，我是一台迷你电子琴

**十个琴键，一块屏幕，和装在小小机身里的音乐。**

## 🎵 我能做什么

我的 7 个音级键和 3 个修饰键可以用来演奏；TFT 屏幕、扬声器和 Wi-Fi 网页让我能显示曲谱、播放音乐，也能陪你练习。手机与电脑端项目还可以帮助整理和传送曲谱。
