ESP32 迷你电子琴 快速试玩

完整模拟

用和实琴一样的十个按键，选曲、跟弹和播放音乐。

默认载入「音乐厅钢琴」。

未开机

单独长按 / 约 1.2 秒进菜单，短按退出。菜单里 Z / X 移动、C 确认、V 返回。自动播放时轻按 , 暂停或继续。

第一次怎么弹
  1. 开机后单独长按 /，进入「选择歌曲」。
  2. 选「和弦练习」。按 C 确认曲目，选「简单 单音」或「复杂 多音」后再确认。
  3. 选「开始演奏」跟弹，或选「播放音乐」听自动演奏。复杂多音的第一个和弦是 Z + C + B。
